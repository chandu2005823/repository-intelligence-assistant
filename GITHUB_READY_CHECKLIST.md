### Common Issues

**Authentication failed?**
- Use GitHub personal access token (not password)
- Get token: https://github.com/settings/tokens

**Permission denied?**
- If using SSH, you need SSH keys set up
- Use HTTPS instead for easier setup

**Files not appearing?**
- Make sure `.gitignore` is correct
- Check `.env` files are actually in `.gitignore`
